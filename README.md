# Маркетинг-проекты

Сайт для Netlify:

- `/` — **DDL V**, список проектов со светофором. Проекты добавляются прямо на сайте: объём работ (задачи из шаблонов или свои), что делается сейчас, сроки, рекламный бюджет, лиды.
- `/#project-<id>` — **страница проекта** для вас и команды: светофор, прогресс, реклама, что делается сейчас; задачи отмечаются прямо там. Сумм оплаты клиента на ней нет.
- `/#finance` — **Финансы**, только по паролю: сколько платит каждый клиент и сколько договорились за месяц, платежи частями (с датами), долги, недоплаты (месяц можно закрыть с недоплатой), ушедшие клиенты, деньги и клиенты по месяцам на графиках. Пароль задаётся при первом входе в раздел.

- `/#leads` — **Лиды агентства**: потенциальные клиенты, которых вы вносите вручную (дата, кто, контакт, источник, услуга, ожидаемый чек, статус «Новый → В работе → Купил / Отказ», комментарий). Цифры за месяц, конверсия и источники клиентов. Открыто всем, у кого есть ссылка. Заявки можно не вбивать руками: кнопка «Вставить заявки» принимает текст вида «Новая заявка: … Имя: … Номер телефона: … Город: … Реклама: …» сразу пачкой, либо такие сообщения можно переслать Telegram-боту. Номера, которые уже есть, второй раз не добавляются.
- `/#tasks` — **Задачи**, по тому же паролю, что «Финансы». Те же задачи, что в Telegram-боте.

## Telegram-бот

Личная тудушка с напоминаниями. Время — по Ташкенту (UTC+5).

- Задачи пишутся обычным текстом: «завтра в 10 позвонить автошколе», «через 2 часа…», «в пятницу в 15:00…», «5 ноября в 12…», «каждый понедельник в 9…», «по будням в 10…», «каждое 1 число в 10…». Без времени — просто в список.
- Напоминание приходит с кнопками «Сделано», «Через час», «Завтра в 9» и «🔁 1 ч · 2 ч · 3 ч · 4 ч»: бот повторяет напоминание с выбранным интервалом, пока задачу не отметят сделанной или не нажмут «Не повторять». Интервал можно задать и текстом: «каждые 2 часа выпить воды». С 22:00 до 9:00 повторы ждут утра.
- Каждое утро в 9:00 — сводка: задачи на день, просроченные, дедлайны проектов (сегодня, завтра, через 3 дня, просроченные), красные проекты.
- Когда проект становится красным — отдельное сообщение. 1-го числа в 10:00 — долги клиентов и кого ждём в этом месяце.
- Команды: /list, /today, /digest, /help. Бот отвечает только владельцу — тому, кто первым нажал Start.

Настройка: переменная окружения `TELEGRAM_BOT_TOKEN` в Netlify (с галочкой «Contains secret values»), затем открыть `/api/telegram/setup` и нажать Start в боте. Проверка токена: `/api/telegram/check`.

## Заявки из Make

`POST /api/leads/hook?key=<LEADS_WEBHOOK_KEY>` принимает заявки из Make (модуль HTTP → Make a request) и сразу добавляет их во вкладку «Лиды».

- Поля можно слать JSON или формой: `name`, `phone`, `city`, `ad`, `client`, `source`, `note`, `date` (понимает и русские названия: «Имя», «Номер телефона», «Город», «Реклама»), либо одно поле `text` с текстом «Новая заявка: …». Сырой формат Meta Lead Ads (`field_data`, `created_time`, `ad_name`, `form_name`) тоже понимается; лишние поля формы попадают в комментарий.
- Дубли по номеру телефона не добавляются. Ответ: `{"ok": true, "added": 1, "duplicates": 0}`.
- Ключ задаётся переменной окружения `LEADS_WEBHOOK_KEY` в Netlify. Проверить адрес: открыть его в браузере (GET).

## Как светофор выбирает цвет

- **Красный**: дедлайн прошёл, бюджет превышен больше чем на 10% или выполнено задач на 25 п.п. меньше, чем прошло времени.
- **Жёлтый**: отставание на 10–25 п.п., потрачено больше 90% бюджета при выполненных меньше 80% задач, до дедлайна 7 дней и меньше при выполненных меньше 90%, или объём работ не расписан.
- **Зелёный**: всё по плану.
- **Готово**: все задачи выполнены.

## Как устроено

- `public/` — страницы сайта.
- `netlify/functions/projects.mjs` — API `/api/projects`, хранит проекты в Netlify Blobs (хранилище `projects`). Любой, у кого есть ссылка, может добавлять, менять и удалять проекты.
- `netlify/seed.mjs` — проекты, перенесённые из claude.ai. Загружаются один раз, когда хранилище ещё пустое.
- `netlify/functions/telegram.mjs` — бот: `/api/telegram/check`, `/api/telegram/setup`, `/api/telegram/hook`.
- `netlify/functions/reminders.mjs` — запускается каждую минуту: напоминания и их повторы, утренняя сводка, красные проекты, долги 1-го числа.
- `netlify/functions/leads.mjs` — API `/api/leads`, хранит лиды агентства в Netlify Blobs (хранилище `leads`).
- `netlify/functions/tasks.mjs` — API `/api/tasks` для вкладки «Задачи».
- `netlify/lib/` — общий код: разбор времени из текста (`parse.mjs`), разбор заявок (`leadparse.mjs`), часовой пояс (`time.mjs`), светофор и долги на сервере.
- `netlify/functions/finance.mjs` — API `/api/finance`, хранит оплаты клиентов в Netlify Blobs (хранилище `finance`). Без пароля данные не отдаются; сумма оплаты не попадает в данные проектов.

## Публикация на Netlify

1. app.netlify.com → **Add new project** → **Import an existing project** → GitHub → `sss077/marketing-dashboard`.
2. Настройки сборки подтянутся из `netlify.toml`, ничего менять не нужно. Нажмите **Deploy**.
3. После каждого изменения в ветке `main` сайт обновляется сам.
