# Маркетинг-проекты

Две страницы для работы с маркетинговыми проектами. Обе работают внутри claude.ai как Artifacts.

## Светофор проектов — `svetofor/`

Здесь вы сами добавляете проекты: объём работ (задачи из шаблонов или свои), что делается сейчас, сроки, бюджет и лиды. Цвет светофора считается автоматически:

- **Красный**: дедлайн прошёл, бюджет превышен больше чем на 10% или выполнено задач на 25 п.п. меньше, чем прошло времени.
- **Жёлтый**: отставание на 10–25 п.п., потрачено больше 90% бюджета при выполненных меньше 80% задач, до дедлайна 7 дней и меньше при выполненных меньше 90%, или объём работ не расписан.
- **Зелёный**: всё по плану.
- **Готово**: все задачи выполнены.

Живая версия: https://claude.ai/artifact/7htsh7iJbsuanhx1P5PisJ

Проекты хранятся в базе Artifact на claude.ai (`claude.use("db")`, коллекция `projects`), а не в этом репозитории. Если открыть `index.html` напрямую в браузере, страница покажет сообщение, что хранилище недоступно.

## Дашборд — `dashboard/`

Выручка, расход, лиды, CPL, ROMI, график по неделям, ROMI по каналам и таблица проектов. Страница сделана на типе Dashboard из claude.ai и использует его API (`dash.data`, `dash.calc`, `dash.draw`), поэтому вне claude.ai она не запускается.

Живая версия: https://claude.ai/artifact/33k29xqusuUPmH1wGSJkiN

`dashboard/data/` — **примерные, выдуманные** данные (`sample_projects.csv`, `sample_weekly.csv`), на которых построен дашборд. Чтобы перейти на реальные данные, замените их своей выгрузкой с теми же колонками.
